# AI Chat App

A simple and responsive AI chat application built with HTML, CSS, JavaScript, Node.js, and Express.

The app connects with the Groq API to generate AI responses and includes features like chat persistence, sticky layout, typing indicators, and a clean modern UI.

---

## Features

- Real-time AI responses
- Responsive chat interface
- Sticky header and input section
- Typing indicator animation
- Auto-resizing textarea
- Enter to send messages
- Local storage chat history
- Clear chat functionality
- Secure API handling with Express
- Mobile-friendly layout

---

## Tech Stack

### Frontend

- HTML
- CSS
- JavaScript

### Backend

- Node.js
- Express.js

### API

- Groq API
- Llama 3.3 70B Model
